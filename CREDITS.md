# Credits

attribution wherever the game is shared; it is also shown in game (main

All from [Sketchfab](https://sketchfab.com), in `aces-client/assets/models/`
(stored with Git LFS). The model files are used as downloaded; the game
scales, rotates and re-centres them when loading (`flight::model_fixup`).
